# 📁 img/ — Panduan Gambar HeyJasmine

Letakkan semua aset gambar di folder ini dengan struktur berikut:

```
img/
├── hero/
│   └── hero-fabric.jpg         ← Foto kain/tekstur utama di hero section
│
├── opening/
│   ├── opening-1.jpg           ← Foto editorial fashion (portrait, 3:4)
│   ├── opening-2.jpg           ← Detail kain / proses jahit (square)
│   └── opening-3.jpg           ← Suasana workshop / studio (square)
│
├── alasan/
│   └── alasan-bg.jpg           ← Foto suasana produksi / behind the scenes
│
├── bonus/
│   └── bonus-bg.jpg            ← Background section bonus (tekstur/lifestyle)
│
└── testimonials/
    ├── alicia.jpg              ← Foto profil Alicia Putri (square, min 80x80px)
    ├── rizky.jpg               ← Foto profil Rizky Mahendra
    └── sinta.jpg               ← Foto profil Sinta Dewi

```

## Cara Menggunakan

Cari komentar `<!-- Replace with: <img ...> -->` di `index.html` — tinggal uncomment dan sesuaikan path.

## Spesifikasi Teknis

| Gambar | Format | Ukuran ideal | Rasio |
|--------|--------|-------------|-------|
| hero-fabric | JPG/WebP | 1200×1600px | 3:4 |
| opening-1 | JPG/WebP | 800×1067px | 3:4 |
| opening-2/3 | JPG/WebP | 800×800px | 1:1 |
| alasan-bg | JPG/WebP | 1000×1000px | 1:1 |
| bonus-bg | JPG/WebP | 1200×800px | 3:2 |
| testimonials | JPG/WebP | 200×200px | 1:1 |

## Tips Foto

- **Nuansa**: soft, natural light — hindari foto dengan warna terlalu jenuh
- **Tone**: cream, beige, putih bersih — sesuai palet brand
- **Konten**: foto kain, proses jahit, editorial fashion clean, detail tekstur
- **Hindari**: foto dengan watermark, terlalu gelap, atau warna mencolok
